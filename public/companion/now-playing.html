Privacy and compatibility

Hosted setup sends sign-in requests to Plex. The sign-in key and account token are held only in this tab’s memory. No access key is sent to the perINKpheral web server. Manual setup works independently of Plex sign-in.

The browser verifies the chosen server during Plex setup and contacts it if you ask to find players. The server receives its access key and any proxy Authorization header you provide. When you fill the settings, your approved device tab receives the selected server and optional player credentials. Save on that device to store them. The app keeps the last confirmed playback metadata on the device for display when the server cannot be reached. Remove the app and choose to forget its data to clear both credentials and metadata. Revoke access separately in Plex if needed.

The device uses the configured server and, if supplied, the direct player address. It does not need a perINKpheral account. Plex handles sign-in under its own privacy policies.
